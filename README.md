## 🚀 Ishga Tushirish (Local Setup)

1. Bog‘liqliklarni o‘rnatish:
   ```bash
   npm install
   ```

2. Dasturchi rejimida ishga tushirish:
   ```bash
   npm run dev
   ```
   Brauzerda [http://localhost:3000](http://localhost:3000) manzilini oching.

3. Ishlab chiqarish (Production) uchun yig‘ish:
   ```bash
   npm run build
   npm run start
   ```
